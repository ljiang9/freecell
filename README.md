# freecell

终端 FreeCell 接龙,纯标准库。

## 玩法

目标:把 52 张牌按花色 A→K 送进 4 个基础堆。

- 8 列牌堆:开局 7,7,7,7,6,6,6,6;列内降序红黑交替
- 4 个自由格:每格暂存 1 张牌
- 空列可以放任意牌(或合法序列)

## 命令

```
c3 f1      第 3 列顶牌 -> 基础堆 1
c3 c5      第 3 列顶牌 -> 第 5 列
c3 c5 3    第 3 列顶部 3 张 -> 第 5 列(受 supermove 上限约束)
c3 fc1     第 3 列顶牌 -> 自由格 1
fc1 c2     自由格 1 -> 第 2 列
h          帮助
q          退出
```

### supermove 上限

一次可移动的最大序列长度 = **(1 + 空闲自由格数) × 2^空列数**
(目标空列本身不计入空列数)。这是经典 FreeCell 规则,本实现严格执行。

### 其他

- `freecell --seed 42` :固定牌局,方便复现/比拼
- `freecell --auto 500 --seed 1` :弱策略机器人随机游走 500 步(回归验证用)

## 设计取舍

- 交互为行输入模式,每步需回车(纯标准库跨平台取舍)
- `--auto` 机器人是随机弱策略,胜率极低,仅用于"零非法移动"的回归验证

## 已知局限

- 无悔棋/存档/计时计分
- 机器人不会解牌,别指望它赢
- 行输入模式,不支持鼠标和单键操作
